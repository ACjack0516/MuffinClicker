# MuffinClicker
click dem muffins

A fun browser-based clicker/idle game where you bake muffins, unlock upgrades, and grow your muffin empire.

> **Status:** Early development

## Play the Game

https://muffinclicker.vercel.app/

## Features

- Click to bake muffins
- Buy upgrades and multipliers
- Idle progression
- Save system
- *(More features coming soon)*
